# Agri-tech / AQUAINTAL

AQUAINTAL is a Smart Water Management and integrated farm dashboard built with React and Vite.

## Features
- Real-time simulation of 5-acre sugarcane farm, 50-hen coop, and 50-fish tilapia tank.
- Live data generation, energy tracking, and water system metrics.
- Built with React, Tailwind CSS, Recharts.
